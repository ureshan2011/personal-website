## How to Get GitHub Student Pack?

Getting started with GitHub Student Pack is pretty easy. There is only one pre-requisite, and that is you need to have a GitHub account created using your **email address issued by your university**. If you do not have a GitHub account, first create an account via this link ([https://github.com/signup](https://github.com/signup?ref=readclub.me)).

Now let's see how to enrol with GitHub Student Pack.

-   **Step 01:** Go to Google, search "github student pack", and visit the first search result.

![Screenshot of searching for GitHub Student Developer Pack on Google](https://readclub.me/content/images/2022/10/Screenshot-2022-10-19-at-8.10.23-PM.png)

*Search result for "github student pack" on Google*

-   **Step 02:** You will see the [GitHub Student Developer Pack webpage](https://education.github.com/?ref=readclub.me) below. Click the "Sign up for Student Developer Pack" button there.

![GitHub Student Developer Pack Website](https://readclub.me/content/images/2022/10/Screenshot-2022-10-19-at-8.10.51-PM.png)

*[GitHub Student Developer Pack webpage](https://education.github.com/?ref=readclub.me)*

-   **Step 03:** Select the "Student" checkbox as your academic status and scroll down.

![GitHub Student Developer Pack Website](https://readclub.me/content/images/2022/10/Screenshot-2022-10-19-at-8.11.32-PM.png)

*Enrolling for the GitHub benefits*

-   **Step 04:** You need to enter your university email address and university/high school name and then add a brief description explaining how you plan to use  GitHub. Then click the "Continue" button.

![GitHub Student Developer Pack Website](https://readclub.me/content/images/2022/10/Screenshot-2022-10-19-at-8.13.58-PM.png)

*Providing details for enrolling with the GitHub Student Pack benefits*

-   **Step 05:** GitHub will request you to upload proof of your academic status. You can take a photo of your student ID card or enrolment confirmation/offer letter. Make sure to take a clear photo of your document and upload it. Select the document type from the dropdown menu and submit.  

![GitHub Student Developer Pack Website](https://readclub.me/content/images/2022/10/Screenshot-2022-10-19-at-8.15.37-PM.png)

*Requested academic status proofs*

![GitHub Student Developer Pack Website](https://readclub.me/content/images/2022/10/Screenshot-2022-10-19-at-8.15.49-PM.png)

*Submission of academic status proof document*

-   **Step 06:** That's it! Now you need to wait sometime until you hear from GitHub. It may not take long, but it takes a couple of days. Once your request is approved, you can check your benefits from the below link. **[https://education.github.com/pack](https://education.github.com/pack?ref=readclub.me)**
